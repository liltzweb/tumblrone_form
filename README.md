# tumblrone order form

Form pemesanan publik untuk website **tumblrone** milik katalog liltz. Website sumber tetap private; repo ini hanya berisi form statis dan tidak memuat foto, audio, atau data pelanggan.

**Live form:** https://arjunafransesco.github.io/tumblrone_form/

## Alur

1. Isi form.
2. Tekan **salin & buka Telegram**.
3. Ringkasan order disalin ke clipboard dan chat [@reeumen](https://t.me/reeumen) dibuka.
4. Paste ringkasan, kirim, lalu lampirkan media secara berurutan.
